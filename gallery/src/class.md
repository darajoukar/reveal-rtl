---

## اهداف این جلسه

در پایان این جلسه می‌توانید:

- ایده‌ی مرتب‌سازی حبابی را توضیح دهید
- آن را روی یک آرایه‌ی کوچک دستی اجرا کنید
- پیچیدگی زمانی آن را بگویید

---

## ایده‌ی اصلی

- عنصرهای کنار هم را مقایسه کن
- اگر ترتیبشان درست نیست، جابه‌جا کن
- بزرگ‌ترین عنصر مثل حباب به آخر آرایه می‌رسد

Note: با پنج دانش‌آموز داوطلب و کارت‌های عدد، الگوریتم را روی تخته اجرا کنید.

---

## مثال

| دور | آرایه |
|---|---|
| شروع | 5، 2، 8، 1 |
| دور اول | 2، 5، 1، 8 |
| دور دوم | 2، 1، 5، 8 |
| دور سوم | 1، 2، 5، 8 |

---

## کد

```python
def bubble_sort(items):
    for end in range(len(items) - 1, 0, -1):
        for i in range(end):
            if items[i] > items[i + 1]:
                items[i], items[i + 1] = items[i + 1], items[i]
    return items
```

## جمع‌بندی و تکلیف

- پیچیدگی زمانی: در بدترین حالت از مرتبه‌ی n²
- ساده، اما برای داده‌های بزرگ کند است
- **تکلیف:** مرتب‌سازی انتخابی را مطالعه کنید
