ارائه‌ی راست‌به‌چپ

پلاگین RTL برای reveal.js

این یادداشت سخنران است. با دکمه‌ی یادداشت در نوار ابزار یا کلید S دیده می‌شود.

نوار ابزار و فهرست

  • کلید M یا دکمه‌ی ☰: فهرست اسلایدها و جستجو
  • دکمه‌های اولین و آخرین اسلاید و نمای شبکه‌ای
  • تایمر ارائه (با رفرش متوقف نمی‌شود) و ساعت
  • کلید T یا دکمه‌ی ▾: پنهان و نمایش نوار ابزار
  • انتخاب تم، یادداشت‌ها و تمام‌صفحه
نوار ابزار بعد از چند ثانیه بی‌حرکتی موس پنهان می‌شود.

فهرست

  • جهت راست‌به‌چپ و کلیدهای برعکس
  • فونت وزیرمتن
    • فهرست تودرتو با تورفتگی درست
  • اعداد فارسی: 1404 و 25 درصد

فهرست شماره‌دار

  1. نصب پلاگین
  2. افزودن CSS
  3. اجرای ارائه

کد و متن دوجهته

دستور npm install reveal.js را اجرا کنید.

Reveal.initialize({
  plugins: [ RevealRTL() ]  // 123 stays Latin
});
