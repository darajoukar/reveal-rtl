# create-reveal-rtl

Start a right-to-left [reveal.js](https://revealjs.com) presentation with [reveal-rtl](https://github.com/darajoukar/reveal-rtl) in one command.

```bash
npm create reveal-rtl my-talk
npm create reveal-rtl my-talk -- --lang ar
npm create reveal-rtl my-talk -- --lang en --title "My talk"
```

You get one `index.html` (slides written in Markdown inside it, loaded from the jsDelivr CDN) and a short `README.md`. Open `index.html` in a browser — no build step, works from disk.
