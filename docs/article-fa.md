# ساخت ارائه‌ی فارسی با HTML در پنج دقیقه

پاورپوینت برای ارائه‌ی فارسی همیشه دردسر داشته است: جهت متن به‌هم می‌ریزد، اعداد لاتین می‌شوند، فونت روی سیستم دیگر عوض می‌شود و فایل نهایی هم سنگین است. ارائه‌ی HTML این مشکل‌ها را ندارد؛ یک فایل است که در هر مرورگری باز می‌شود. معروف‌ترین ابزار برای این کار [reveal.js](https://revealjs.com) است، ولی برای فارسی ساخته نشده بود. **reveal-rtl** این جای خالی را پر می‌کند.

![reveal-rtl در حال کار](https://raw.githubusercontent.com/darajoukar/reveal-rtl/main/docs/demo.gif)

## شروع با یک دستور

اگر Node.js روی سیستم شما نصب است، این دستور یک ارائه‌ی آماده‌ی فارسی می‌سازد:

```bash
npm create reveal-rtl my-talk
```

پوشه‌ی `my-talk` ساخته می‌شود و داخلش یک فایل `index.html` است. همین فایل را با دابل‌کلیک در مرورگر باز کنید؛ ارائه آماده است. نه سروری لازم است و نه مرحله‌ی build.

## اسلایدها را با Markdown بنویسید

اسلایدها داخل همان فایل با Markdown نوشته می‌شوند. هر `---` یک اسلاید جدید می‌سازد و هر چه بعد از `Note:` بیاید، یادداشت سخنران است:

```markdown
# عنوان ارائه

---

## فهرست

- مورد اول
- مورد دوم

Note: این یادداشت را فقط ارائه‌دهنده می‌بیند.
```

## چه چیزهایی خودکار درست می‌شود؟

- **جهت راست‌به‌چپ** در همه‌ی تم‌ها، همراه با فهرست‌ها و جدول‌ها؛ کلید ← اسلاید بعدی را می‌آورد و کشیدن انگشت روی گوشی هم درست کار می‌کند.
- **اعداد فارسی** در متن، شماره‌ی اسلاید و خروجی PDF. داخل کد اعداد لاتین می‌مانند.
- **فونت وزیرمتن** داخل خود پکیج است، پس بدون اینترنت هم ارائه درست نمایش داده می‌شود.
- **تاریخ شمسی و قمری** با یک تگ ساده:

```html
<time data-jalali></time>
<time data-hijri></time>
```

## نوار ابزار برای ارائه‌دهنده

پایین صفحه یک نوار ابزار هست که با کلید <kbd>T</kbd> پنهان می‌شود:

- **فهرست اسلایدها** با جستجو (کلید <kbd>M</kbd>)؛ جستجو حتی «<span lang="ar">ي</span>» و «<span lang="ar">ك</span>» عربی را هم پیدا می‌کند.
- **تایمر**؛ با کلیک روی آن مدت ارائه را بدهید تا معکوس بشمارد و در دقایق آخر زرد و بعد قرمز شود.
- **نشانگر لیزری** (<kbd>Z</kbd>) و **قلم** (<kbd>D</kbd>) برای نوشتن روی اسلاید. نوشته‌ها ذخیره می‌شوند و در PDF هم می‌آیند.
- **پنجره‌ی سخنران** (<kbd>S</kbd>) که آن هم فارسی و راست‌به‌چپ است.
- **خروجی** PDF، Markdown، JSON و یک فایل HTML آفلاین که همه‌چیز داخلش است.

## زبان عربی و انگلیسی

همه‌ی برچسب‌ها به سه زبان هستند. برای ارائه‌ی عربی کافی است زبان را عوض کنید تا ارقام هم عربی شوند:

```js
Reveal.initialize({ rtlOptions: { lang: 'ar' } });
```

## بررسی متن فارسی

یک ابزار کوچک هم همراه پکیج هست که متن اسلایدها را بررسی می‌کند و «<span lang="ar">ي</span>» و «<span lang="ar">ك</span>» عربی، فاصله به‌جای نیم‌فاصله و ارقام قاطی را گزارش می‌دهد. چیزی را خودکار تغییر نمی‌دهد:

```bash
npx reveal-rtl-lint my-talk
```
